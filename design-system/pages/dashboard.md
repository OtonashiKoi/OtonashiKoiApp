# Dashboard 頁面規範（頁面覆寫）

此頁面為後台主要入口，重點資訊以卡片形式呈現：即時數據、快速動作、近期事件與報表預覽。

版面要點
- 最大寬度：`max-w-6xl`，在寬螢幕居中顯示。
- 上方保留頂欄高度 64px，側欄 72px 寬可收折。
- 內容區塊：
  - 頂部為 KPI 卡片帶摘要（4-up on desktop, 2-up on tablet）
  - 中段為主要工作區：左側為列表/表格（70%），右側為輔助面板（30%）或活動時間軸。
  - 底部為最近操作記錄或系統健康狀態卡片。

元件優先順序
- KPI Cards（快速檢視）
- 搜尋 + 篩選（在表格上方）
- 列表 / 表格（行動裝置 fallback 為卡片清單）
- 側欄詳細 Pane（點選列時顯示）

互動要點
- 點擊表格列顯示右側詳細 Pane，且可從 Pane 進行快速編輯。
- 所有主要動作（新增/匯出/匯入）以顯眼主按鈕呈現，次要動作為次色按鈕。

視覺語言
- 以白色為主畫布，卡片帶微陰影，文字使用深色；重要數字使用 `text-primary`。

## 編輯格式

```
旁白：文字                    → narration 節點
你：文字                      → 玩家台詞
<角色名>：文字                → 該引路人台詞
[選擇] 提示文字               → choice 節點
  - 選項文字 → 分支代號
[戰鬥] 戰前旁白                → battle 節點（mustWin，對手＝該職業的引路人）
[進化] 徽章id ｜ 旁白          → transfer 節點（消耗一轉徽章＋扣登記費）
[分支:代號]                   → 分支起點標記
[合流]                        → 兩條分支在此收束（之後不可再有發放）
```

**⚠️ 鐵則**：有分支的職業，兩條線各自要有自己的 `[戰鬥]` 和 `[進化]`，不可共用。
（choice 只跳轉、不記變數，合流後無從得知玩家選了哪條 → 共用會發錯徽章。）

**共同骨架**：① 徵兆 → ② 引路人現身 → ③ 問答 → ④ 選擇（有分支才有）→ ⑤ 戰鬥 → ⑥ 進化 → ⑦ 短收

# 組隊爬塔 v1 規則定稿 LIST

> 🧪 **公開入口目前暫停**：`TOWER_ENABLED = false`；只有 `src/shared/towerAccess.js` 白名單中的音無恋可由 Discord 與 Web 測試。

用途：這份清單用來對照「組隊爬塔」下一季版本的核心戰鬥規則。程式是實際行為來源；若重開或改規則，程式與本文必須在同一變更中同步。

## 已定稿規則

1. 隊伍最多 6 人。
2. 玩家建立或加入隊伍時必須選擇坦、補、輸出其中一種站位；開始前可自行更換，站位不限制人數。
3. 坦：HP ×1.3、ATK ×0.7、自己提供的隊伍光環 ×0.5。
4. 補：HP ×0.7、ATK ×0.7、自己提供的隊伍光環 ×1.3。
5. 輸出：HP ×1、ATK ×1.2、自己提供的隊伍光環 ×0.5。
6. 組隊時要顯示行動軸預覽。
7. 行動軸依 AGI 速度條計算，卡片、Buff、光環若改變 AGI，要即時影響排軸。
8. 怪物本身也有 AGI，必須一起排進行動軸。
9. 速度相同時排序：速度條溢出量、AGI、DEX、加入順序。
10. 怪物行動只攻擊一名存活隊員，選擇順序固定為坦 → 補 → 輸出；同站位按加入順序。
11. 怪物身上的 debuff、暈眩、降防等效果由全隊共享。
12. 已移除塔專屬職業與二轉光環；塔內只收集一般戰鬥區域原有的隊伍光環。
13. 同職業同效果光環不疊加，只取最高值；不同職業可共存。
14. 陣亡玩家提供的 Buff、光環、支援效果會失效。
15. 暈眩會跳過怪物下一次行動；重複暈眩只刷新，不無限堆疊。
16. 全隊成員都能拿到本次通關獎勵。
17. 打輸時領取目前通關獎勵並解散，下次重新組隊挑戰。
18. 全塔共 71 層；70、71 層固定為煉獄烈焰狼王(B)。

## 本版已執行

1. 後端戰鬥改成玩家與怪物共同使用 AGI 速度條排軸。
2. 後端移除舊版固定多動門檻。
3. 後端每次行動前重新計算存活隊員光環與即時 AGI。
4. 後端怪物行動改為依站位優先順序選擇單一目標。
5. 後端怪物暈眩改成跳過下一次怪物行動。
6. 後端怪物 debuff 與暈眩狀態在全隊攻擊間共享。
7. 後端治療光環改成全隊回復。
8. 後端同職業同效果光環只取最高值。
9. Discord 面板移除舊版 AGI 40/80 的 ×2/×3 顯示。
10. Discord 面板改成顯示速度條行動軸預覽。
11. Discord 戰報顯示怪物實際攻擊的目標。
12. Discord 與 Web 都可在建立／加入時選站位，並在大廳內更換自己的站位。
13. 70、71 層固定狼王，共 71 層。

## 三、二轉系統

**地基已完成並通過測試（2026-07-20）**，各職業的二轉內容尚未設計。

### 規則（已定案並實作）

| 規則 | 決定 | 狀態 |
|---|---|---|
| 門檻 | Lv.35 | ✅ |
| 前置 | 必須持有對應的一轉徽章 | ✅ |
| 試煉條件 | **以該一轉職業累積出戰次數**（`battle_as_<職業>`） | ✅ |
| 試煉難度 | 第 1／2／3 個 = **350 ／ 700 ／ 1000 場** | ✅ |
| 一轉徽章 | 不銷毀，保留在背包可自由換裝 | ✅（沿用既有機制） |
| 可持有的二轉徽章上限 | **3 個** | ✅ |
| 同時進行的二轉試煉 | 只能 1 條 | ✅ |
| **同一個一轉職業的分支** | **只能選一個**（選了聖劍士就永遠不能再拿大劍） | ✅ |

### 已建好的東西

- **`src/shared/jobAdvancement.js`** — 二轉單一來源：門檻常數、11 個一轉職業對應表、
  二轉分支表 `T2_BRANCHES`（**目前全空，等逐一設計後填**）、徽章判定與查詢 helper。
  之後新增二轉只要動這個檔 + 一支 upsert script。
- **11 個 `battle_as_<職業>` 任務指標** — DC 端與網頁端兩個記錄點都已接上（這兩處歷來
  容易漏改一邊，現在是同一個 helper 產生的），後台任務編輯器下拉也補齊。
- **五道閘門** — 全部實作在 `weeklyQuestService`，含可見性、進度累積、領獎三個層面各自把關。
  任務只要標 `isT2Trial: true`，五道閘門自動生效。

### 測試

## 1. 這是什麼遊戲？

**一句話定位**：一個寄生在 Discord 內、由直播/打卡帶動、以裝備強化與職業構築為核心的回合制 MMO 文字遊戲。

**核心循環**：
```
打怪 → 拿經驗 + 金幣 + 裝備 + 怪物卡
  ↓
升等 → 解鎖更強區域、職業徽章
  ↓
強化裝備 → 變更強
  ↓
挑戰更難內容（高級區 / 精英區 / 爬塔 / PK / 世界王）
  ↓
回到打怪
```

**特殊之處**：
- 介面以 Discord Bot 為主，輔以 Web 後台與 Web 玩家面板
- 玩家身分與直播綁定，看直播 / 打卡會給遊戲內獎勵
- 抖內 / 抖內累積制有額外回饋（鑽石發放）

## 2. 玩家會遇到什麼？玩家旅程拆解

### 階段 A：第一個 5 分鐘（Onboarding）

玩家進入後會被 16 個新手任務串接，這是最關鍵的留存設計：

| # | 任務 | 條件 | 獎勵 |
| --- | --- | --- | --- |
| 1 | 完成直播綁定 | bind 直播帳號 | 200 金 + 布帽 |
| 2 | 首次出戰 | 打 1 場 | 120 金 + 木製單手劍 |
| 3 | 首次勝利 | 贏 1 場 | 180 金 + 木盾 |
| 4 | 累計造成 500 傷害 | damage 500 | 200 金 + 布衣 |
| 5 | 完成 1 次打卡 | checkin | 150 金 + 道具 |
| 6 | 裝備任一裝備 | equip 1 次 | 200 金 + 木製單手斧 |
| 7 | 完成 1 次強化 | enhance 1 次 | 240 金 + 布披風 |
| 8 | 出戰 10 次 | battle 10 | 400 金 + 木製雙手劍 |
| 9-11 | 連擊/迴避/格擋各 3 次 | 各種戰鬥行為 | 220 金 + 對應武器 |
| 12 | 擊暈 3 次 | stun_count 3 | 260 金 + 木製雙手槌 |
| 13 | 角色死亡 3 次 | death 3 | 260 金 + 道具 |
| 14 | **Lv.10 並獲得職業徽章** | 等級+職業 | 300 金 |
| 15 | 連擊 20 次 | combo 20 | 500 金 + 道具 |
| 16 | 全部完成 | onboarding_complete | **屬性重製藥水** |

**設計意圖**（從任務排列看）：
- 第 1-6 任務逼玩家「綁定直播、打過、贏過、強化過」——核心功能體驗一次
- 第 8-13 任務逼玩家體驗 5 種戰鬥機制（連擊、迴避、格擋、擊暈、死亡），順便分發 5 把武器
- 第 14 任務是分水嶺：Lv10 + 職業徽章=玩家正式「成形」
- 完成全部 → 屬性重製藥水 = 給玩家「我可以重做一次build」的安全網

### 階段 B：Lv10 解鎖職業（成形期）

10 個職業徽章，每個徽章解鎖條件 = **武器種類 + 基礎屬性閘門**：

| 職業 | 武器 | 屬性條件 | 主軸 | 徽章加成 |
| --- | --- | --- | --- | --- |
| 劍士 | sword_1h/2h | STR+DEX>10 | 盾擊反擊 | STR+2 VIT+3 DEX+2 |
| 戰士 | axe_1h/2h | STR+VIT>10 | 低血量反撲 | STR+4 VIT+1 LUK+2 |
| 矮人戰士 | mace_1h/2h | VIT+STR>10 | 擊暈強化 | STR+1 VIT+5 DEX+2 |
| 盜賊 | dagger | AGI+DEX>10 | 連擊+中毒 | STR+2 AGI+4 LUK+2 |
| 法師 | staff_2h | INT+AGI>10 | 法杖防穿 | VIT+1 INT+5 LUK+2 |
| 治療師 | staff_1h | INT+VIT>10 | 在場光環 | VIT+2 INT+4 DEX+2 |
| 弓箭手 | bow | DEX+AGI>10 | 命中要害+閃避反擊 | AGI+1 DEX+5 LUK+2 |
| 軍師 | sword_1h | AGI+INT+DEX>10 | （三屬性 hybrid）| AGI+4 INT+2 DEX+2 |
| 詩人 | bow | DEX+AGI+LUK>10 | （三屬性 hybrid）| AGI+2 DEX+4 LUK+2 |
| 結界師 | staff_1h/2h | INT+VIT+DEX>10 | （三屬性 hybrid）| VIT+3 INT+3 DEX+2 |

**玩家體感觀察**：
- 前 7 個職業是「主流職業」，2 屬性條件好達成
- 後 3 個（軍師/詩人/結界師）是「進階職業」，需要 3 屬性 hybrid，明顯偏 build 多元化
- 職業 ≠ 永久綁定，徽章可以換 → 玩家可以根據裝備調職業

### 階段 C：Lv10-20 中級區（堆裝期）

中級區 12 隻怪，等級 9-15，包含 **2 隻 Boss + 1 隻稀有金怪（小金/中金）**：
- 主要產出：B/C 階裝備、怪物卡、金幣
- 稀有金怪（小金/中金）= 高金幣產出
- 森林系列（樹樹、古樹、獵豹、巫師、盜賊、之獸）= mid 區的後段內容

### 階段 D：Lv20+ 高級區（核心 endgame 入口）

15 隻怪，等級 20-35，3 隻 Boss：
- **城堡魔像(B)** Lv28 / **古城將軍(B)** Lv30 / **廢都魔王(B)** Lv35
- A 階裝備主要來源
- 13 種怪物卡（古城系列）

### 階段 E：精英區 + 爬塔 + PK + 世界王（多軸 endgame）

| 系統 | 玩什麼 | 入場/門檻 |
| --- | --- | --- |
| **大史王（精英）** | Lv35 巨型 Boss，HP 95 萬 | 入場費 5000 金 |
| **爬塔（單人）** | 多層挑戰，行動格耗盡或全滅結束 | 進度型 |
| **組隊爬塔 V1** | 最多 6 人，AGI 速度條排軸，光環/Buff 共享 | 組隊 |
| **PK 擂台** | 玩家對戰，職業效果完整移植，含下注 | 排行制 |
| **世界王** | 週循環跨玩家 Boss，多階段 | 自動參與 |

### 階段 F：日常循環

每天和每週的固定任務：

**每日（4 個）**：出戰 5 次（250 金/120 EXP）、勝 3 場（300/140）、傷害 3000（320/160）、打卡（180/100）
**每週（7 個）**：出戰 30、勝 20、傷害 5 萬、打卡 5 次、裝備 10 次、強化 3 次、全完成 → **屬性重製藥水**

## 3. 系統間的串聯（生態圖）

```
            ┌──────────────┐
            │  直播 / 打卡 │ ─→ 金幣、EXP、道具
            └──────┬───────┘
                   ↓
            ┌──────────────┐
   ┌──────→ │   打怪戰鬥   │ ←──────┐
   │        └──┬───────────┘        │
   │           │                    │
   │      經驗 + 金幣 + 裝備 + 卡  │
   │           ↓                    │
   │     ┌──────────┐               │
   │     │  強化裝備 │ ←─ 寶石/金幣 │
   │     └──┬───────┘               │
   │        ↓                       │
   │     ┌────────────┐             │
   └─────┤ 變強，挑戰 ├──→ 高級區/精英區/爬塔/PK/世界王
         └────────────┘
                                    │
   ┌──────────────┐                 │
   │  拍賣場       │ ←── 玩家之間裝備買賣
   └──────────────┘                 │
                                    │
   ┌──────────────┐                 │
   │  金幣商店     │ ←─ 道具 / 消耗品 / 屬性藥水
   └──────────────┘
```

**雙向價值流**：
- 直播/打卡 → 戰鬥資源（鑽石 / 道具 / 經驗）
- 戰鬥 → 裝備 / 卡 / 金幣 → 強化 / 商店 / 拍賣
- 拍賣場讓玩家之間直接交易，金幣有流通去處

## 4. 玩家會感受到什麼？（情緒設計觀察）

### ✅ 設計亮點

1. **明確的等級閘門**：Lv10 解鎖職業是一個「畢業典禮」，新手期到此告一段落，給玩家成就感。
2. **職業多選擇 + 可換性**：徽章不是綁定，10 個職業給出 build 自由度。
3. **多軸 endgame**：精英區（單人挑戰）、爬塔（解謎/組隊）、PK（社交對抗）、世界王（公會式）—— 不同玩家口味都有去處。
4. **每日/每週任務的「最終獎勵」設計**：完成全部 → 屬性重製藥水，給玩家「我可以調 build」的安全感。
5. **賭鬼強化（+1 才開放）**：基礎強化先保護新手，進階玩家才解鎖「賭一把」模式，分層友善。
6. **怪物卡收集**：每隻怪可收集對應卡片（special 槽 ×3），有橫向蒐集向遊玩。
7. **直播綁定 + 抖內回饋**：把外部社群行為直接接進遊戲。

### ⚠️ 可能的玩家痛點

1. **新手任務 16 個**：太長。玩家在第 4-8 任務間最容易流失（剛打完前面興奮、Lv10 還沒到、不知道下一步）。
2. **mid 區跨度**：mid 怪等級 9-15，但 hard 入口要 Lv20，**中間 16-19 等沒有專屬內容**，玩家可能在 mid 區農到無聊。
3. **稀有金怪（小金/中金）**：HP 只有 1000-3000 但金幣 1800-7500——是「彩票怪」，需要刷新運氣才遇到。對沒運氣的玩家可能體感差。
4. **大史王入場費 5000 金**：對 Lv20-25 的玩家是不小負擔，輸了會痛。
5. **PK 下注系統**：玩家若沉迷下注，可能跟核心循環脫鉤。
6. **裝備 221 件**：選擇豐富但也可能「選擇癱瘓」——後台需要好的篩選/推薦機制。
7. **Web 面板偏功能化**：根據 `web-game-blueprint.md` 自己的反省，Web UI 像 dashboard 不像 game hub，缺少「第一眼帶入冒險感」。

### ❌ 看不到的東西（可能需要補）

從資料看，目前 **沒有明顯的**：
- 公會 / 隊伍長期歸屬（除了爬塔的臨時組隊）
- 玩家對玩家的非戰鬥社交（聊天可能有但沒查到結構）
- 賽季 / 排行榜重置機制（PK 第一名公告 ≠ 賽季）
- 成就系統（任務 ≠ 成就）
- 故事/任務劇情（任務都是 metric-based，沒有 NPC 對話劇情）

## 5. 數值健康度快評

### 經驗曲線
**真實需求單位**：一般活躍玩家每天玩 6 小時，約 5 天可由 Lv1 滿到 Lv50。

換算目標：
- Lv1→50 目標總時長：約 30 小時。
- 每天 1 小時：約 30 天。
- 每天 2 小時：約 15 天。
- 每天 3 小時：約 10 天。
- 每天 6 小時：約 5 天。

目前基準試算（`scripts/probe-real-combat-1to50.js`，真實戰鬥流程 / 單人劍士基準 / 每場 +15 秒操作）：
- Lv1→50：約 29.8 小時。
- 擊殺：約 783 隻。
- 戰鬥場次：約 3,794 場。
- 金幣：約 1,830,065。
- 裝備：約 319.5 件。
- 怪物卡：約 8.31 張。
- 強化石：約 482.8 顆。

里程碑：
- Lv10：約 2.3 小時。
- Lv20：約 4.2 小時。
- Lv30：約 7.6 小時。
- Lv40：約 17.7 小時。
- Lv50：約 29.8 小時。

**判讀**：現在 EXP 曲線以「30 小時滿等」為主需求；若覺得滿等前拿到的怪物卡太少，應優先調整掉落率或保底，而不是拉長 EXP。

### 裝備階級分佈
- A 階 61 件、B 階 51、C 階 53、D 階 57 → 平均分佈，不偏科
- 槽位 13 種，每槽位 8-16 件 → 變化夠
- 武器類型 9 種（劍/雙手劍/槌/雙手槌/斧/雙手斧/匕首/弓/法杖/雙手法杖）→ 對應 7 個職業綁定，匹配清楚

### 道具經濟
- 消耗品 17 種（藥水、寶石、爬塔藥水、屬性重製）
- 強化寶石 4 階（A/B/C/D），階級越高需要的寶石越稀有
- 收藏品 5 個（音無系列圖片）→ 純收藏，不影響戰力

## 6. 從玩家視角的「建議改版方向」

按優先級排序：

### P0（影響留存的核心問題）
1. **新手任務瘦身或分階段**：16 個任務拆成「前 6（必過）+ 中 6（推薦）+ 進階 4（選打）」，避免任務疲勞。
2. **填補 Lv16-19 內容空檔**：mid 區後段可以新增 Lv15-19 的 boss 群組，或讓 hard 區降為 Lv18 入場。

### P1（增進深度的內容）
1. **正式賽季制**：PK / 爬塔 / 世界王 各自有賽季，週期性重置 + 賽季獎勵 = 持續動力。
2. **公會 / 固定隊伍系統**：組隊爬塔現在是臨時隊，加入「公會」概念可以讓 6 人持續一起玩。
3. **成就系統**：例如「收齊所有 D 階怪物卡」、「強化到 +10」、「PK 100 勝」等，給長期玩家蒐集目標。

### P2（體驗優化）
1. **Web 玩家面板改造為「冒險入口」**：按 web-game-blueprint.md 自己的計畫，把首頁從 dashboard 改為 hub。
2. **稀有金怪掉落保底**：例如「進入 mid 區 N 次必出 1 次小金」，避免運氣差的玩家體感差。
3. **裝備推薦系統**：根據職業 + 當前裝備推薦下一件升級目標。

### P3（內容擴展）
1. **怪物 NPC 劇情**：給 zone 加入故事線，讓玩家覺得不只在打 metric。
2. **更多賭鬼強化內容**：給高階玩家更多「賭一把」的選擇（賭爆擊強化、賭專屬詞綴等）。

## 7. 一句話總結

**equipmentGAME 是一個「系統完整、循環健康、endgame 多元」的 Discord 遊戲**，核心戰鬥/裝備/職業/強化的設計已經紮實，目前最大的成長空間在 **新手期分階段、中期內容填空、社交歸屬感（公會/賽季）、Web 入口戲劇化**。

對 362 位現有玩家而言，遊戲已經提供 **每日有事做、每週有目標、每階有挑戰**——下一階段的關鍵是「讓他們有理由 3 個月後還在玩」。

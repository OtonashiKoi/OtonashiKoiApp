# 10/1 新季度玩法整理：日常養成與組隊挑戰

> 狀態：提案／未實作。2026/09/21 依使用者方向整理；「已定方向」是產品要求，不代表程式或正式 DB 已改好。其餘標示「建議」的細節仍待討論。
> 9/21 執行更新：錨點停用已實裝並部署，玩家資料已依保留規則清理；其餘玩法變更尚未實作。
> 開季目標 2026/10/1；工程安全與發布驗收接續 [開季 LIST](SEASON_2026_10_LAUNCH_CHECKLIST.md)。本文件取代該清單原先尚未定案的玩法定位。

## 一、本季與上一季的差別

**本季核心：平常輕鬆刷怪養角色，想挑戰機制就組隊、選職責，攻略新的怪物與 BOSS。**

### 已定方向

1. 錨點暫時關閉、不開放；保留系統與既有資料，供未來重新開放。
2. 一般刷怪區降低機制負擔。
3. 既有世界王也降低機制負擔。
4. 重要機制集中到組隊區。
5. 組隊區沿用之前可選自己站位的功能，配置新的怪物與 BOSS。

| 面向 | 上季／現有結構 | 本季目標 |
| --- | --- | --- |
| 角色養成 | 裝備、職業、錨點等多層效果 | 本季先以等級、職業、裝備與既有養成系統為主；錨點停用 |
| 日常刷怪 | 怪物效果與戰鬥規則需要逐項理解 | 好進場、好理解、能穩定累積養成資源 |
| 既有世界王 | 有部位、階段、部分王的特殊機制 | 大型共同討伐；減少攻略門檻，保留王的外觀與招牌特色 |
| 組隊玩法 | 測試中的組隊爬塔、坦補輸出站位，沿用既有怪池 | 本季主打挑戰內容；專屬新怪、新 BOSS、隊伍分工 |
| 難度來源 | 各處分散的機制與養成強度 | 基礎內容看養成；組隊內容同時看養成及配合 |

## 二、整體遊玩流程

登入／新手引導 → 一般區練等與收裝 → 轉職、強化、調整裝備 → 挑戰簡化的既有世界王 → 選坦／補／輸出並加入組隊區 → 攻略新怪及新 BOSS → 取得進階獎勵並繼續養成。

建議保留不組隊也能完成的基礎成長與日常；組隊提供額外挑戰與追求，不把基本轉職、主線推進或每日全清全部綁在揪團上。組隊獎勵的優勢需有界線，避免回頭讓日常區失去意義。

## 三、錨點：完整暫停、資料保留

錨點目前會影響裝備、屬性、治療轉傷、吸血、承傷與光環。停止開放應涵蓋以下整條流程，不能只隱藏圖鑑或按鈕。

- [ ] **展示**：關閉錨點導覽、裝備入口、取得提示及錨點專屬圖鑑／任務入口；既有物品若仍可見，標示「本季暫停」。
- [ ] **取得**：盤點錨點任務、掉落、箱包、商店、故事獎勵及其他發放路徑；阻止新取得與舊任務直接呼叫領取。
- [ ] **使用**：Web／Discord／API 均不能裝備或使用錨點；舊裝備方案與人物切換也不能繞過。
- [ ] **效果**：已裝錨點、其他人物快照、組隊快照中的錨點皆不提供屬性或被動，涵蓋一般戰鬥、世界王、組隊、PK、掛機及任何相關計算。
- [ ] **保留**：不刪既有錨點、永久取得紀錄或劇情進度；先建立安全保留方式，避免強制卸下時背包滿而遺失。換季仍須依永久／季節物品規則另處理，停用本身不等於刪除。
- [ ] **替代獎勵**：依賴錨點獎勵的主線／新手／每日全清，不因停用而無法完成；替代獎勵需另定。
- [ ] **平衡**：以「零錨點」重新驗證職業生存、補師治療、坦職承傷、輸出及怪物強度；不能只關掉力量來源而維持原難度。

注意：程式中有名稱含「記憶錨定卡包」的每日獎勵。不能只用 anchor 字樣批次停掉所有任務或卡片；要按實際道具類型與效果分類。**一般怪物卡片、卡片圖鑑、鑲嵌石目前未被要求關閉。**

## 四、一般刷怪區：穩定養成

**玩家目的**：練等、收裝、金幣、材料、任務、測試配裝。

建議保留區域與怪物等級差異、七屬性與抗性、掉落特色、基本攻防與可理解的狀態。需要團隊配合的判定改放組隊區，避免一般怪同時疊多個免疫、即死、指定時窗或複雜階段。

建議的機制預算：一般小怪 0–1 個簡單特色、區域精英／小王最多 1 個核心特色。這是設計目標，實際移除／降級名單先由正式 DB 怪物效果盤點產生，不直接大量刪資料。

- [ ] 每個區域列出「推薦等級／裝備、主要掉落、保留特色、停用機制」。
- [ ] 調整必要的 HP、傷害、費用與掉落，確保關錨點後各職業仍能日常成長。
- [ ] 戰報說明簡潔，死亡原因可理解；以強化裝備或換區為主要改善途徑。
- [ ] 一般刷怪不要求選站位或等隊友。

## 五、既有世界王：保留大型討伐、降低攻略門檻

**玩家目的**：與全服共同打王、取得裝備／材料、累積貢獻與領獎。

建議保留既有王的身分、美術、血池與基本貢獻獎勵。大史王、古龍王、地獄狼牙王，以及若本季沿用的活動王，逐一建立簡化表；活動王是否沿用另決定。

| 類型 | 建議處理 |
| --- | --- |
| 大血量、攻防／屬性差異 | 保留並用零錨點基準重新調整 |
| 部位 | 可保留外觀及目標選擇；降低必須照順序、打錯使全隊受罰的要求 |
| 血量階段 | 視每隻王保留單純變強或一招招牌技，避免多層規則同時切換 |
| 詠唱／控制累積／特殊破綻／進場即死 | 若需玩家配合，停用或簡化其舊王版本；設計精神可在新組隊王重新運用 |
| 排行、掉落與寶箱 | 先保留既有公平結算，再調整獎勵定位；不因機制簡化而漏發或重複發 |
| 單人世界王 | 若沿用同一王資料，也要同步簡化；每日次數與帳號共用規則先維持 |

建議每隻舊王最多保留 1 個容易理解的核心特色。不是所有王變成相同數值，也不把舊王整套機制不加整理地搬給新王。

## 六、組隊挑戰區：本季的新內容

> 最新組隊規則以 [組隊企劃 V2](SEASON_2026_10_PARTY_PLAN_V2.md) 為討論依據。下列舊建議（五關、關間準備、獎勵方式等）未獲定案；與 V2 衝突者不再採用。坦克增防增血減傷害；輔助增血、光環與治療但減防；輸出增傷害但減防、迴避與血量。自動戰鬥、坦→輸出→輔助、全滅判敗，結算骰裝。

9/21 延伸討論稿：[首發副本設計](SEASON_2026_10_DUNGEON_DESIGN.md)，涵蓋入場、站位、五關怪物、重試與獎勵，尚未實作或定案。

### 找到的既有基礎（2026/09/21 程式核對）

- SPA `battle.tsx` 的組隊爬塔畫面有「選擇站位」及「我的站位（開始前可更換）」。
- 目前最多六人，選項是坦／補／輸出；這是戰鬥職責，尚非自由移動格子。
- 已有建立／加入房間、公開房列表、密碼房、換站位、隊長開始／逐關推進、撤退、道具與隊伍戰報的程式入口。
- `towerRoles.js` 已有承傷目標優先順序與 HP／ATK／光環倍率；不代表玩家選補就自動擁有治療技能，能力仍要與職業及裝備對上。
- 目前共 71 層、最低 Lv.30，怪池與固定王仍沿用既有內容。這些是舊塔設定，不自動成為新組隊区的定案。
- 房間放在記憶體，服務重啟會掉房；結算仍需補齊持久識別、失敗補發及不可重複領取。
- 站位測試通過，既有組隊模擬可執行；尚未驗收新的專屬怪物／BOSS 或完整多人瀏覽器流程。

### 建議玩法

建立／加入 → 選坦、補或輸出 → 查看職責與怪物預告 → 準備 → 小怪教機制 → 精英加深 → BOSS 綜合考驗 → 通關／失敗結算。

- **坦**：承接關鍵傷害，讓保護隊友有實際價值。
- **補／輔助**：提供治療、護盾、增益或控制；不能把全部價值只算成輸出。
- **輸出**：完成擊殺及爆發窗口，與坦補共同影響通關。
- 先沿用既有回合結算與站位選擇。新機制應能由隊伍配置、裝備、技能及回合狀態完成；若要加入戰鬥中按鍵打斷、躲格或即時換位，必須另設操作階段與同步流程，不能假裝既有核心已支援。
- 建議開戰前全員準備確認、角色能力提示、明確缺位提醒。是否硬性限制「一定幾坦幾補」待平衡測試，先不鎖死特定職業。

### 首發內容規模（建議，未定名）

先完成 **1 個完整主題組隊區，3 種新小怪＋1 精英＋1 BOSS**。以少量完整內容確保 10/1 能玩，再增加第二區；最低人數、入場等級、時長、次數／費用與具體數值待定。

| 教學順序 | 新怪物概念（暫名） | 教玩家什麼 |
| --- | --- | --- |
| 1 | 重擊守衛 | 可預告的重擊由坦位承接，坦倒下後目標如何轉移 |
| 2 | 瘴氣術士 | 持續隊伍壓力，需要補血／護盾維持；不預設尚未存在的驅散功能 |
| 3 | 蓄能獵手 | 明確回合的破綻期，輸出與隊伍增益產生價值 |
| 4 | 精英指揮官 | 先組合前面兩種機制，測試續戰與分工 |
| 5 | 區域 BOSS | 用清楚的階段順序綜合考驗，先少量機制，不同時塞所有免疫／即死／控制需求 |

這是製作模板，正式名稱、美術、故事、數值與招式尚未決定。新怪有自己的資料與掉落表，不直接覆蓋既有世界王。

### 獎勵定位（建議）

- 一般區提供基礎裝備、金幣與日常材料；既有王提供進階養成／王系獎勵。
- 組隊區提供專屬裝備選擇、製作材料、稱號或外觀；不再用錨點作為本季核心獎勵。
- 參與且符合完成条件的隊員各有通關報酬，坦補不因傷害較低拿不到基本獎勵；額外貢獻獎勵另算。
- 進場費、斷線、離隊、失敗、重連及重複請求的獎勵規則須先寫清楚；不以單純加大掉寶或塞另一種必農貨幣代替玩法。
- 舊塔「通關給一般區攻擊祝福」也要重新決定，避免不打組隊就明顯落後日常效率。

# 二轉引路人・設定檔

> 類型：**劇情內容設定／未完整入庫**。建立 2026-08-03；2026-08-10 核對現行轉職不依賴這 11 段劇情，玩家可透過已啟用的 `t2_transfer` 任務轉職。
> 世界觀依據：序章、第一章既有內容。
> 使用者定案：**他們是虛擬世界裡的居民，不是職訓所的人**；概念是「讓玩家成長的存在」。
> 後續劇情會壓在虛擬世界，所以這 11 位是常駐角色，不是一次性 NPC。

## 二、職業體系的世界觀對應

⚠️ **重要修正（使用者定案）**：職業體系**不屬於現實的職訓所**。
職訓所只是入口——報到、適性測驗、然後登入。進去之後的事，是虛擬世界自己的規矩。

| 遊戲機制 | 世界觀對應 |
|---|---|
| 一轉試煉（屬性＋武器門檻＋出戰 10 場） | **虛擬世界的公會**發的委託／認定。公會承認你能走這條路，給你徽章 |
| 職業徽章 | 公會發的憑證，但它**不只是憑證**——它會隨著你的使用而變化 |
| 徽章熟練度 Lv1→20 | 徽章在你手上被「用熟」。它記得你每一場怎麼打的 |
| 屬性值隨等級成長（50%→100%→Lv20 150%；效果百分比全程完整） | 徽章與持有者磨合的過程。剛拿到時屬性尚未完全展開 |
| Lv20 | 徽章已經被你用到極限——**它開始需要別的東西** |
| 二轉劇情 | **特殊的事情**：你遇見了引路人。那場相遇本身就是觸發條件 |
| 一轉徽章消失、二轉徽章出現 | **不是換發，是進化。** 同一枚徽章變成了別的東西 |
| 二轉徽章從 Lv1 重練 | 進化後它又不認得你了——形狀變了，得重新磨合 |
| 一轉徽章不可再取得 | 它沒有被回收，它**變掉了**。世上不再有那一枚 |
| 費用 25 萬／100 萬／300 萬 | **公會的變更登記費**（定案）。進化本身不收錢——引路人不要錢、也不經手。
但你的身分變了，公會的紀錄要整套重做：委託等級、報酬級距、擔保額度。
第二次、第三次越來越貴，因為「重複變更者的紀錄最難維護」（公會原話） |

> 設計註：徽章**自主進化**這條線，讓「舊徽章被消耗」從一個系統行為變成了角色成長的隱喻，
> 也讓「二轉從 Lv1 重練」有了不需要辯解的理由——不是懲罰，是它變成新東西了。
>
> **費用的敘事用法**：進化是神祕的、安靜的、沒有人能解釋的；然後**下一秒公會的扣款通知就來了**。
> 這個落差是刻意的——虛擬世界再怎麼不可思議，它底下還是壓著一套會跟你收錢的系統。
> 每一段轉職劇情的收尾都可以用這個反差收，但不要每次都用同一種寫法。

## 三、引路人（總則）

**他們不屬於任何組織。** 公會發徽章、辦委託；引路人跟公會也沒有關係——
他們本來就在那裡，比公會存在得更久。遇見他們不是流程，是**事故**。

- **身分**：虛擬世界的居民。各自把某一條路走到了盡頭，然後停在那裡。
- **概念**：**讓玩家成長的存在**。他們不「教學」，而是讓你在他們面前看見自己還缺什麼。
- **動機**：⚠️ **待定**——他們為什麼要讓外來者成長？這是全系列最關鍵的一個問號，
  也是最適合接序章伏筆（「不要忘記我」）的接口。在定案前，劇本裡不要給出答案，
  但可以讓每位引路人各自透露一點不一致的說法。
- **外觀共通**：沒有制服、沒有識別證。與虛擬世界的環境「太過融合」——
  久到分不清是他們待在那裡，還是那裡長成了他們的樣子。
- **語氣基調**：各自不同，但共同點是**不熱血、不說教、不喊招式**。
  他們不急，因為他們已經沒有要去的地方了。
- **與公會的關係**：公會知道有這些人存在，但**沒有登記、沒有派任、也管不到**。
  公會的說法是「那屬於個人際遇」——這句話在公會手冊裡出現過三次，每次意思都不太一樣。
- **觸發方式**：不是你去找他們，是**徽章帶你去的**。
  熟練度滿了之後，你會在某個走過很多次的地方，看見以前沒有的東西。

> 寫作禁忌：不要寫成公務員（那是第一章報到人員的位置），也不要寫成熱血師傅。
> 他們比較接近「一個在那裡待了很久、看過很多人來去的人」。

## 五、轉職劇情的骨架

每一段照這個走，長度約 40~60 節點：

```
① 徵兆（2~4 節點）—— 徽章開始不對勁：發熱／自己動／某個走過很多次的地方出現了以前沒有的東西
② 引路人現身（3~5）—— 在虛擬世界裡，他們本來就在的地方
③ 問答（6~10）—— 引路人問一個「你這條路到底在幹嘛」的問題
④ choice ＝二轉分支（有分支的職業才有）
⑤ 試煉 ＝ battle 節點（mustWin）
⑥ 進化（5~8）—— **不是交付、不是換發**。徽章在你手上變成別的東西，引路人只是在旁邊看著
⑦ transfer 節點 → 收尾
```

### ⚠️ 分支職業的結構鐵則

劇情系統的 `choice` **只是跳轉、不記變數**，合流之後無從得知玩家選了哪條路。
→ **有分支的職業，兩條線必須各自走完（各有自己的 battle 與 transfer）**，
　 寧可重複幾個節點，也不能共用一個 transfer 節點——那會發錯徽章。

目前有兩條分支的職業：**劍士**（聖劍士／劍鬼）、**盜賊**（影舞者／盜靈）。
其餘 9 個職業目前只有一條分支。
⚠️ **劍鬼與盜靈本季 `seasonLocked:true` 封印**（`src/shared/jobAdvancement.js:129`、`:214`）——
劇本仍照兩條線寫，封印是轉職端另一道獨立閘門，開放與否不影響劇本結構。

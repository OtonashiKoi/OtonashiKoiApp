# 治療師（Healer）

> 類型：一轉玩法摘要；精確數值與當回合治療時序以 MongoDB 徽章及 `combatLoop.js` 為準。只累計實際補回 HP，滿血溢補不算任務進度。

定位：隊伍支援專家，提供在場即生效的治療光環與隊伍增益。

玩法重點：
- 治療師會在隊伍中提供每回合回復（例如回復最大 HP 的百分比）與小幅提升全隊傷害，適合長期消耗戰與支援型玩家。
- 因為是「在場生效」，只要治療師在同一場戰鬥中，隊員即可享受光環；離場或換裝後效果會移除。

建議配裝：智力（INT）與耐久（VIT）傾向，若希望同時兼具法術強度與生存，可平衡裝備。

玩家小技巧：
- 隊伍有治療師時，可安心採取耗血換輸出的策略（例如坦承受傷再由治療師回補）。
- 治療師搭配能提升隊伍傷害的裝備，能同時增加團隊的持續輸出能力。

（原始定義可在 `scripts/upsert-job-healer.js` 查看）

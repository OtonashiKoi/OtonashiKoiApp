# 盜賊（Rogue）

> 類型：一轉玩法摘要；雙持副手追擊已移除，精確連擊、毒與技能規則以 MongoDB 徽章、`combatStats.js` 與 `combatLoop.js` 為準。

定位：高機動短促輸出，匕首專精，擅長快速打斷與持續傷害。

玩法重點：
- 匕首以 AGI 為主攻並自帶連擊加成，適合高頻率輸出；副手仍可提供裝備屬性，但不會自動追擊。
- 擅長讓敵人中毒（毒為每回合扣血且可疊加），適合消耗型打法。

建議配裝：敏捷（AGI）與暴擊傾向，匕首為主，若想提高穩定性可搭盾。

玩家小技巧：
- 想打持續傷害：利用毒性效果累積傷血，配合高頻率攻擊加速殘血處理。
- 想提高瞬間傷害：提高 AGI、爆擊與職業技能覆蓋；不要把副手誤認為額外攻擊次數。

（原始定義可在 `scripts/upsert-job-rogue.js` 查看）

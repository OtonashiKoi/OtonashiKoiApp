# 劍士（Swordsman）

定位：前排近戰戰士，擅長單手劍與雙手劍，穩定與爆發兼具。

玩法重點：
- 單手劍：適合搭配盾牌或副手武器，能提高格擋或連擊傷害，玩起來更耐久或有穩定輸出。
- 雙手劍：輸出更高且有斬殺機會（當怪物血量低於門檻時有機率一擊終結），適合追求收割與爆發的玩家。

建議配裝：以力量（STR）與耐久（VIT）為主；單手劍走防禦/支援流，雙手劍走高輸出流。

玩家小技巧：
- 想穩定存活並支援隊伍：選單手劍 + 盾，利用格擋降低被秒風險。
- 想要高爆發收怪：使用雙手劍，注意怪物血線以提高斬殺命中率。

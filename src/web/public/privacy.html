隱私權政策 Privacy Policy

最後更新日期：2026 年 5 月 24 日　|　生效日期：2026 年 5 月 24 日

1. 服務簡介

equipmentGAME（以下稱「本服務」）是一款結合 Discord 機器人與網頁前端的多人線上遊戲，由 otonashikoi 開發與營運。本服務透過 Discord OAuth 進行身份驗證，並可選擇性整合 Twitch、YouTube 等第三方平台，用於辨識玩家於直播頻道之會員身分，據此提供遊戲內專屬獎勵。

2. 我們收集的資料

2.1 透過 Discord OAuth

  • Discord 使用者 ID — 玩家唯一識別
  • Discord 顯示名稱 — 遊戲內顯示
  • Discord 頭像 URL — 遊戲內顯示

我們不會讀取您的 Discord 私訊、好友清單、伺服器清單、或任何訊息內容。

2.2 透過 Twitch / YouTube OAuth（選擇性綁定）

Twitch：

  • Twitch 使用者 ID、顯示名稱
  • Twitch 訂閱狀態（針對特定頻道）— 判定您是否為頻道訂閱者，據此給予遊戲獎勵

YouTube：

  • YouTube 頻道 ID、顯示名稱
  • YouTube 頻道會員身分（針對特定頻道）— 判定您是否為頻道會員，據此給予遊戲獎勵

我們只會查詢您是否為特定 Discord 伺服器擁有者所屬頻道之會員或訂閱者，不會讀取您訂閱的其他頻道、觀看紀錄、留言、按讚、播放清單、或您頻道的影片內容。

2.3 遊戲行為資料

  • 玩家等級、經驗值、屬性點
  • 持有道具、裝備、貨幣（金幣、鑽石）
  • 戰鬥紀錄、任務進度、打卡紀錄
  • 邀請碼使用紀錄、交易紀錄

3. 我們如何使用您的資料

收集到的資料僅用於：

  • 遊戲功能運作：身份識別、進度儲存、戰鬥模擬、獎勵發放
  • 會員專屬獎勵：依據 Twitch / YouTube 會員身分提供遊戲內獎勵
  • 服務改善：分析匿名化使用模式
  • 問題排除：處理錯誤、回應使用者支援請求

我們不會將您的資料用於廣告投放、銷售給第三方、跨服務追蹤、訓練 AI 模型。

4. Google API 使用聲明（Limited Use）

本服務使用 Google YouTube Data API v3，並符合 Google API Services User Data Policy，包括「有限使用」(Limited Use) 之要求。

具體而言：

  • 我們只請求遊戲核心功能所必需的 OAuth scope（例：youtube.channel-memberships.creator）
  • 從 Google API 取得的資料僅用於本政策第 3 條所述用途
  • 不會轉售、不會用於廣告、不會用於人為審閱（除非取得您明示同意，或法律要求，或為偵測詐欺/安全問題）
  • 不會將 Google API 資料傳輸給第三方（除提供您要求之服務所需，例如本服務的雲端託管服務商）

5. 資料儲存與保護

  • 儲存位置：MongoDB 資料庫，部署於受信任之雲端基礎設施
  • 傳輸加密：所有 API 通訊透過 HTTPS / TLS 加密
  • 存取控制：僅本服務管理員可存取資料庫
  • 第三方 OAuth Token：加密儲存於資料庫，不在日誌中明文輸出
  • 資料保留：帳號活躍期間持續保留；自最後一次登入起 365 天內未活動將進入清除程序

# 六大屬性系統完整參考

## 基本設定

### 屬性上限
```
STR (力量) : 上限 60
AGI (敏捷) : 上限 60
VIT (體質) : 上限 60
INT (智力) : 上限 60
DEX (靈巧) : 上限 60
LUK (幸運) : 上限 60
```

## 詳細功能表

### STR (力量)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **攻擊力 (ATK)** | `baseStat × weaponMult` | ∞ | 近戰基礎傷害，由武器倍率決定 |
| **單手劍傷害** | `ATK × 1.0` | ∞ | sword_1h 的基礎 ATK |
| **雙手劍傷害** | `ATK × 1.0` | ∞ | sword_2h 的基礎 ATK（倍率×7） |
| **槌類傷害** | `ATK × 1.0` | ∞ | mace_1h/2h 的基礎 ATK |
| **斧類傷害** | `ATK × 1.0` | ∞ | axe_1h/2h 的基礎 ATK |
| **匕首傷害** | `ATK × 1.0` | ∞ | dagger 的基礎 ATK |

**相關職業**：戰士、劍士、矮人戰士

---

### AGI (敏捷)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **迴避率** | `min(50, AGI × 0.5 + dodgeBonus)` | 50% | 躲避怪物攻擊機率，弓 +30%（弓上限無強制） |
| **連擊機率** | `min(80, 3 + AGI × 0.5 + comboBonus)` | 80% | 每回合額外追擊機率，匕首 +20% |
| **戰鬥速度** | `1500 - ((min(AGI,40)-1)/39 * 1000)` | 500ms | 每回合演出延遲，AGI 40 達最快 0.5s |
| **AGI 優勢（玩家 AGI > 怪物 AGI）** | | | 依據優勢幅度觸發不同效果 |
| ├─ AGI 差 > 2 | 條件式 | ∞ | 第 1 回合玩家先手，怪物無法反擊 |
| └─ AGI 差 > 5 | 條件式 | ∞ | 玩家每回合攻擊，怪物只在**偶數回合**反擊（第 2/4/6...回合） |

**相關職業**：盜賊、弓箭手

---

### VIT (體質)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **最大 HP** | `VIT × 15 + 50` | ∞ | 玩家血量上限 |
| **防禦率 (DEF)** | `min(75, VIT × 2)` | 75% | 對怪物攻擊的百分比減傷 |
| **傷害浮動下限** | `min(0.9, 0.5 + INT × 0.01)` | 0.9 | 自身傷害最低倍率（INT 縮小，VIT 無關） |

**相關職業**：戰士（低血量反撲，HP <35%）

---

### INT (智力)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **法杖傷害** | `baseStat = INT（用於 staff_1h/2h）` | ∞ | 法杖使用者的基礎 ATK = INT × 倍率 |
| **傷害浮動下限** | `min(0.9, 0.5 + INT × 0.01)` | 0.9 | INT 每點 +0.01，上限 0.9（穩定傷害） |
| **怪物攻擊次數** | `monsterAtk = 2`（法杖固定） | 2 | 法杖使用時，怪物每回合攻擊 ×2 |
| **無視防禦** | `bypassDefPct = 50`（法杖固定） | 50% | 法杖無視怪物 DEF 的 50% |

**相關職業**：法師

---

### DEX (靈巧)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **命中率 (HIT)** | `min(100, 70 + DEX)` | 100% | 攻擊命中怪物的機率，基礎 70 |
| **弓傷害** | `baseStat = DEX（用於 bow）` | ∞ | 弓使用者的基礎 ATK = DEX × 3.5 |
| **弓要害率** | `min(80, 35 + DEX × 0.45)` | 80% | 弓箭手獨有，命中要害機率 |
| **弓迴避加成** | `dodgeBonus = +20%`（弓固定） | ∞ | 弓使用時迴避 +20%（無上限） |

**相關職業**：弓箭手

---

### LUK (幸運)
| 功能 | 計算 | 上限 | 說明 |
|------|------|------|------|
| **爆擊率 (CRIT)** | `min(100, LUK × 0.3)` | 100% | 造成傷害 ×2.5 的機率 |
| **爆擊倍率** | `2.5× 基礎傷害` | 2.5× | 會心一擊的傷害加成 |

**說明**：爆擊獨立於弓要害，可以同時觸發（傷害疊加）

## 計算公式集

### 攻擊力
```
ATK = baseStat × weaponMult
  where baseStat:
    - sword/mace/axe/dagger → STR
    - staff → INT
    - bow → DEX
```

### 傷害浮動
```
浮動範圍 = [INT縮小下限, 1.3]
  下限 = min(0.9, 0.5 + INT×0.01)
  最低 = 0.5
最終傷害 = base × random(下限 ~ 1.3)
```

### 防禦減傷
```
最終傷害 = ATK × (1 - DEF/100)
DEF上限 = min(75%, VIT×2)
```

### 戰鬥速度 (AGI)
```
延遲(ms) = 1500 - ((min(AGI,40)-1)/39 * 1000)
  min 延遲 = 500ms (AGI ≥ 40)
  max 延遲 = 1500ms (AGI = 1)
```

## 注意事項

**職業平衡設計**：
- 每職業主要驅動 1-2 個屬性
- 同時投資多屬性效果會遞減（例：弓需要 DEX+LUK，但不能全投 DEX）

**屬性上限 60 的意義**：
- AGI 40 達戰鬥速度最快上限（0.5s/回合）
- 其他屬性到 60 仍有完整收益
- 設計時考慮這個非對稱性

**未來調整指南**：
- 修改屬性時，同步更新此文檔中的公式和數值
- 新增屬性功能時，在本文檔最後添加版本記錄
- 團隊設計時直接參照本文檔避免誤差

## 怪物卡片技能系統

### 概述
- 每隻怪物對應一張怪物卡片（特殊裝備，特殊槽位）
- 怪物卡片包含 `monsterCardSkill` 結構，可在戰鬥中被觸發
- 玩家亦可裝備怪物卡片於 special_1/2/3 槽位，卡片技能將被觸發

### 技能觸發機制
| 條件 | 機率 | 頻率 | 備註 |
|------|------|------|------|
| **怪物卡片技能** | 5% | 每回合最多 1 次 | 怪物在戰鬥中自動裝備 |
| **玩家卡片技能** | 5% | 每回合最多 1 次 | 玩家在 special_1/2/3 裝備怪物卡片時觸發 |

### monsterCardSkill 數據結構
```
{
  key: string,              // 技能唯一標識（待實現各技能）
  name: string,             // 技能名稱（顯示用）
  description: string,      // 技能敘述（可選）
  effect: {
    type: string,           // damage | heal | buff | debuff | ...
    value: number           // 技能數值（根據類型含義不同）
  },
  procEffects: array        // 觸發效果列表（Buff/Debuff 副作用）
}
```

### 技能效果類型（設計中）
- `damage`：對怪物造成固定或按比例傷害
- `heal`：回復玩家或隊友 HP
- `buff`：給予玩家臨時強化（攻擊/防禦/速度等）
- `debuff`：給予怪物臨時弱化（降低傷害/防禦等）
- 其他：根據需求擴展

### 代碼位置
- **技能觸發邏輯**：`src/shared/combatLoop.js:282-320`（玩家攻擊前檢查）
- **怪物卡片查詢**：`src/bot/handlers/monsterZoneHandlers.js:620-636`
- **卡片數據庫**：`db-backup/items.json`（monsterCardOf 欄位）
- **怪物卡片列表**：`db-backup/monsters.json` 與 items.json 的 monsterCardOf 關聯

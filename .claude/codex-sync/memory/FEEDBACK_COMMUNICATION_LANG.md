# 溝通語言規範

**規則**：任何需要問用戶、需要用戶許可、或需要用戶決策的事項，**一律用繁體中文詢問**。

## 涵蓋範圍

### ✅ 用繁體中文詢問的情況
- 問「你要怎麼做？」（多選項）
- 問「確認這樣改可以嗎？」（許可）
- 問「有什麼要補充的嗎？」（澄清）
- 問「要我實裝嗎？」（決策）
- 問「哪個方案比較好？」（選擇）
- 問「還有其他要求嗎？」（補充）

### ❌ 不需要繁體中文的情況
- 自己分析和推導過程（可以用任何語言）
- 執行代碼、查詢文件（英文註解或中文都可）
- 顯示計算結果（表格、數據可用任何語言）

## Why
用戶是中文母語者，用繁體中文詢問時更清楚、更自然、更容易做出決策。

## How to apply
每次涉及以下動詞時，檢查是否需要用繁體中文：
- ask（詢問）
- confirm（確認）
- decide（決策）
- choose（選擇）
- clarify（澄清）
- permit（許可）

如果是，改用繁體中文重新表述。

---

## 例子

### ❌ 錯誤
```
Should I implement the skill system now, or focus on NPC interactions first?
```

### ✅ 正確
```
我們現在要先實裝技能系統，還是先做 NPC 互動？
```

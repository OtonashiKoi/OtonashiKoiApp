# 怪物卡片技能系統

## 核心機制

### 系統概述
- **24張怪物卡片**：一對一對應所有怪物，裝備於 special_1 槽位
- **技能觸發**：怪物 30%、玩家 5%，每回合最多 1 次
- **雙重觸發源**：怪物自動裝備 + 玩家可主動裝備

### 觸發邏輯優先級與機率
1. **優先檢查怪物卡片**：怪物自動裝備的卡片（在 monsterEquipped.special_1）→ **30% 觸發機率**
2. **次要檢查玩家卡片**：玩家手動裝備的卡片（在 options.equipped 的 special_1/2/3）→ **5% 觸發機率**
3. **只觸發其中之一**：每回合最多一張卡片發動技能

## monsterCardSkill 數據結構

```javascript
{
  key: null,                    // 待設計：技能唯一識別碼
  name: null,                   // 待設計：技能名稱（如「暴衝」「嘔吐」）
  description: null,            // 待設計：技能敘述（可選）
  effect: {
    type: null,                 // 待定：'damage'|'heal'|'buff'|'debuff'|'stun'|...
    value: 0                    // 待定：技能數值（倍率%、固定值等）
  },
  procEffects: []               // 待設計：副作用 Buff/Debuff（如「中毒」「虛弱」）
}
```

## 設計方向（預計效果類型）

### 怪物卡片技能示例
| 怪物 | 卡片名 | 預估技能 | 說明 |
|------|--------|---------|------|
| 小史(小) | 小史(小)卡 | - | 待設計 |
| 跳蚤戰士 | 跳蚤卡 | 連續跳躍 | 造成多段小傷害 |
| 地精劍士 | 地精卡 | 鬼魅斬 | 造成高傷害 + 躲閃機率 |
| ... | ... | ... | 全 24 隻待設計 |

### 預期效果類型
- **damage**：固定傷害 / 百分比傷害
- **heal**：回復玩家 HP（固定值或百分比）
- **buff**：增加玩家短期能力（攻擊/防禦/迴避/爆擊率等）
- **debuff**：減弱怪物短期能力
- **stun**：眩暈怪物（禁止反擊一定回合）
- **反擊**：玩家受到傷害時自動反擊
- **複合**：多個效果組合（如傷害 + 減防）

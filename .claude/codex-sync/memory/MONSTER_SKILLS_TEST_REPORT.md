**測試結果**:

- ✅ 石頭 BLOCK_CHANCE+8% - 格擋機率提升

**驗証**: 所有屬性 Buff 都正確轉換為戰鬥統計數值，並正確應用於傷害計算

### 2️⃣  DOT 傷害（持續傷害）測試
**目標**: 驗証中毒傷害每回合計算

**測試場景**: 玩家初始 200 HP，受到 10% 中毒，持續 1 回合
```
期望: 中毒傷害 = 200 × 10% = 20 HP
實際: 收到 20 HP 傷害 ✅
```

**驗証**: DOT 傷害計算邏輯正確，並正確應用 damagePercent 參數

### 3️⃣  效果過期機制測試
**目標**: 驗証 1 回合效果在第 2 回合自動清理

**測試場景**: 應用 1 回合 STR+5 Buff，進行 3 回合戰鬥
```
回合 1: STR 提升有效，怪物受到加強傷害
回合 2: STR 效果應已過期，傷害恢復正常
回合 3: 無此測試
```

**驗証**: cleanExpiredEffects() 函數正確移除過期效果

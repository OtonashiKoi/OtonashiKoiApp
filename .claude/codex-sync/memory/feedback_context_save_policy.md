---
name: 對話接近上限時存記憶的工作流程
description: 當 token 使用量接近 90% 時，主動將當前進行中的工作狀態存入記憶，讓下次對話可以從記憶繼續而非重新讀取大量檔案
type: feedback
---

當對話 token 使用量接近 90% 時，主動執行以下步驟再繼續：

1. 將當前**進行中的任務狀態**寫入一個新的 project 記憶檔（例如 `project_current_work.md`），內容包含：
   - 正在做什麼功能/修什麼 bug
   - 已完成哪些步驟（含檔案路徑和關鍵改動摘要）
   - 尚未完成的步驟
   - 任何重要的設計決策或注意事項

2. 更新 MEMORY.md 加入該檔案的索引行

3. 告知用戶：「token 快到上限了，已存好進度記憶，下次開新對話直接繼續」

**Why:** 每次對話因 context 壓縮後重新讀取大量檔案會消耗大量 token，用記憶替代可大幅節省成本。

**How to apply:** 在每次長對話中主動監控進度，不要等到 context 耗盡才行動，在 90% 時主動觸發。下次對話開始時優先讀取 project 進度記憶，而非重新探索程式碼。

# 屬性系統改動同步須知

**規則**：每次修改 STR/AGI/VIT/INT/DEX/LUK 相關代碼或數值時，**必須同步更新** `ATTRIBUTES_SYSTEM.md`。

## 涵蓋範圍

### 需要同步的改動
- ✅ 屬性計算公式（ATK、DEF、命中、迴避等）
- ✅ 屬性上限值變更（如 AGI 從 40→50 上限）
- ✅ 職業對屬性的利用（新增職業效果）
- ✅ 武器倍率或屬性綁定變更
- ✅ 新增屬性應用場景

### 不需要同步的改動
- ❌ UI 顯示方式改變（功能不變）
- ❌ 敘述詞語調整（機制不變）
- ❌ 單純代碼重構（邏輯相同）

## 同步步驟

1. **改動代碼**（例：修改 combatStats.js 的 AGI 公式）
2. **找到相應段落**（在 ATTRIBUTES_SYSTEM.md 中找到該屬性）
3. **更新公式**（改動「計算」欄位或版本記錄）
4. **版本記錄**（在文尾添加改動日期和內容）

## 例子

改動前：
```
| **迴避率** | `min(50, AGI × 0.5 + dodgeBonus)` | 50% |
```

改動後（如改為 AGI × 0.6）：
```
| **迴避率** | `min(50, AGI × 0.6 + dodgeBonus)` | 50% |
```

加版本記錄：
```
| v1.1 | 2026-04-20 | AGI 迴避加成改為 0.6（從 0.5） |
```

## Why
屬性系統是戰鬥平衡的核心。不同工作分頭推進時，如果屬性文檔沒同步，會造成設計混亂或數值矛盾。

## How to apply
- 設計師/開發者改動屬性時，提 PR 時一併提交 ATTRIBUTES_SYSTEM.md 的更新
- Code review 時檢查屬性改動是否有同步文檔
- 每週檢視一次文檔是否與代碼一致

## 🏗️ 系統架構

### 職業檢測系統
```javascript
// combatStats.js 行 103-150
const jobId = String(jobEq?.itemId || jobEq?.id || "").toLowerCase();
const jobName = String(jobEq?.itemName || jobEq?.name || "").toLowerCase();

const hasSwordsmanBadge = jobId.includes("swordsman") || jobName.includes("劍士");
const hasWarriorBadge = jobId.includes("warrior") && !jobId.includes("dwarf");
// ... 類似邏輯適用所有職業
```

### 傷害計算層級
```
基礎傷害 = ATK × (1 - finalDef/100) + 隨機浮動
      ↓
職業倍率應用 (弓 ×1.2, 法杖 ×1.15, 戰士低血 ×1.15)
      ↓
爆擊檢測 (LUK 驅動, ×2.5)
      ↓
職業特效 (命中要害 ×1.5, 連擊 ×1.1)
      ↓
最終傷害
```

### 條件觸發系統
| 職業 | 觸發條件 | 效果 |
|------|----------|------|
| 弓箭手 | 武器 = 弓 | 命中要害 |
| 劍士 | 裝備 = 單手劍+盾 | 格擋反擊 |
| 戰士 | 血量 < 35% | 傷害 ×1.15 |
| 矮人 | 血量 > 90% | 擊暈 +5% |
| 盜賊 | 武器 = 匕首 | 連擊加速 |
| 法師 | 武器 = 法杖 | 穿防 |
| 治療師 | 無 | 被動光環 |

# 🎮 DC (Discord) 個人資料系統

- **打卡簽到** - 每日簽到
- **選集合包** - 道具購買

- **🎯 裝備強化** - 裝備升級系統

## 📊 個人資料面板內容

### 獨立三個區域顯示（新結構）

#### 【職業】區
```
職業：[職業名稱] (Job [等級])
例：職業：Novice (Job 1)
```
**說明**：獨立顯示當前職業和職業等級

#### 【職業特性】區
顯示職業名稱，**穿上正確的武器時顯示該職業的特性**

**情況 1：只穿職業徽章（無正確武器）**
```
職業特性：劍士
```

**情況 2：穿職業徽章 + 正確武器**
```
職業特性：劍士
啟用中：格擋反擊
```

**職業與武器對應表**
| 職業 | 正確武器 | 特性 |
|-----|--------|------|
| 劍士 | 單手劍 (sword_1h) | 格擋反擊 |
| 戰士 | 雙手斧 (axe_2h) | 低血傷害倍增 |
| 矮人 | 雙手槌 (mace_2h) | 高血擊暈加成 |
| 盜賊 | 匕首 (dagger) | 連擊加速 |
| 法師 | 法杖 (staff_1h/2h) | 穿防無視 |
| 治療師 | 法杖 (staff_1h/2h) | 隊伍光環 |
| 弓箭手 | 弓 (bow) | 命中要害 |

#### 【NPC Buff】區（可選）
```
【NPC Buff】
[Buff名稱] (效果數值) (1回合)
[Buff名稱] (效果數值) (1回合)
...

例：
【NPC Buff】
經驗加成 (1.3) (1回合)
最終傷害提升 (1.15) (1回合)
```
**說明**：
- 只在玩家有被 NPC 給予的臨時 Buff 時顯示
- 顯示 activeEffects 中的所有 Buff
- **所有 NPC Buff 都是 1 回合效果**
- 格式：Buff 中文名稱 + 效果數值 + **(1回合)**

### 1. 基本素質 【基本素質】
| 屬性 | 顯示格式 | 說明 |
|-----|---------|------|
| STR | STR: X (+Y) | 力量 (基礎 + 裝備加成) |

| HP | ❤️ | 410 | 生命值 |

#### 職業特性 (Trait)
```
職業特性：[職業名稱]
例：刻士撤擊 (Swordsman Counter-Attack)
```

### 3. 配用中 (Equipped Items)
顯示當前穿著的所有裝備：
```
皮甲     🎒   木製單手劍 +3    皮甲風 +1    銅成指(左) +1    銅鍊目錄 +1    嘴口罩     頭盔 +2    皮甲 +1

**說明**：
- 各種道具/裝備顯示
- `+數字` 表示裝備強化等級
- `[標籤]` 表示特殊分類（如[精號]、[職業]）

### 4. 資產 【資產】
```

## 📈 數值計算邏輯

### 等級經驗
- **當前等級 EXP**：現有經驗值
- **總需求 EXP**：升級所需總經驗
- **還差**：計算 = 總需求 - 當前

### 基本素質加成
- **基礎值**：職業基礎屬性
- **(+Y)**：來自裝備的加成
- **總計**：基礎 + 加成

### 戰鬥能力計算
- **HP**：VIT 相關計算
- **ATK**：STR + 武器攻擊力 + 裝備加成
- **DEF**：VIT / 2 + 防具防禦 + 裝備加成
- **CRIT**：LUK × 某倍數 + 裝備加成
- **速度**：AGI 相關計算
- **迴避**：DEX 相關計算

## 🎯 重要規則

### 職業系統
- **【職業】區**：顯示當前職業名稱和職業等級
- **【職業特性】區**：顯示穿著的職業道具名稱（只顯示名稱，不顯示詳細效果）
- 職業由穿著的**職業徽章**決定
- 更換職業徽章會立即更新【職業】和【職業特性】區
- 不同職業有獨特的戰鬥能力加成

### 裝備系統
- 顯示當前所有穿著裝備
- 可在**裝備編**界面進行切換
- 裝備加成會實時更新戰鬥能力數值

### 等級進度
- **玄奖等級**：可能是某種評分或品質等級（如 SS 級）
- **Job 等級**：職業等級（Novice = Job 1）
- **Base 等級**：主角色等級

### 資產顯示
- **金幣**：遊戲內貨幣（通過戰鬥/任務獲得）
- **鑽石**：付費貨幣（氪金或特殊任務獲得）

## 🔄 Buff/Debuff 在 DC 中的顯示

### NPC Buff 區
**新增獨立的【NPC Buff】區顯示玩家當前的臨時效果**

**Buff 來源**：
- NPC 給予的臨時增益效果
- 存儲在玩家的 `activeEffects` 陣列中
- **所有 NPC Buff 都是 1 回合效果**（戰鬥中消耗一回合後消失）

**顯示規則**：
- 只在玩家有活躍的 Buff 時顯示【NPC Buff】區
- 空白區不顯示（無活躍 Buff = 不顯示此區域）
- 每行顯示一個 Buff：`Buff名稱 (效果數值) (1回合)`
- 使用 EFFECT_NAME_ZH 映射表獲得中文名稱

**範例**：
```
【NPC Buff】
經驗加成 (1.3) (1回合)
最終傷害提升 (1.15) (1回合)
```

**與戰鬥的關係**：
- 所有 Buff 在戰鬥中會影響最終的戰鬥能力數值
- DC 個人資料顯示 Buff 的**原始效果參數** + **回合數**
- 實際的傷害/防禦計算在戰鬥邏輯中進行
- 每回合戰鬥後，Buff 持續回合數減 1

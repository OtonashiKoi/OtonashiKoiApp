# UI/UX 設計師工作流

**角色**: UI/UX 設計師  
**專用 Agent**: Plan（強化設計能力）  
**工作語言**: 簡潔 + 視覺化思考  

---

## 🎨 超簡單觸發詞

```
[畫]   = 視覺設計、原型、組件設計
[設計] = 用戶流程、架構、交互設計
[改]   = 修改設計、優化排版、調整配色
```

---

## 🏷️ 領域標籤

| 標籤 | 場景 |
|------|------|
| `@admin` | 後台管理系統 UI |
| `@item` | 道具、物品相關 UI |
| `@player` | 玩家資訊、頻道 UI |
| `@game` | 遊戲主頁面、戰鬥 UI |

---

## 💻 常用命令

### 設計後台
```bash
[設計] @admin 後台儀表板佈局和用戶流程
[畫] @admin 玩家搜尋表單設計
[改] @admin 側邊欄導航配色

[設計] @item 道具編輯器交互流程
[畫] @item 道具卡片 & 屬性面板

[設計] @player 玩家資訊頁設計
[畫] @player 玩家頭像 + 統計資訊佈局
```

### 設計遊戲前端
```bash
[設計] @game 戰鬥 UI 用戶流程
[畫] @game 技能快捷欄組件
[改] @game 傷害數字 & 特效演出

[設計] @player 玩家頻道設計
[畫] @player 聊天氣泡 & 表情選單
```

## 📐 設計系統 (自動加載)

建立後自動記憶加載的設計規範：

```json
"autoLoad": [
  "DESIGN_SYSTEM.md",        // 色彩、排版、規則
  "COMPONENT_LIBRARY.md",    // 按鈕、表單、卡片
  "ADMIN_UI_SPECS.md",       // 後台 UI 規格
  "GAME_UI_SPECS.md"         // 遊戲 UI 規格
]
```

**好處**: 第二次設計同一區域，自動套用規範 ✨

## 🎯 輸出格式建議

### 設計規格
```
## 後台儀表板設計

### 頁面佈局
- Header: 導航 + 用戶資訊
- Sidebar: 功能菜單
- Content: 主要內容區

### 色彩方案
- 主色: #2563eb
- 次色: #64748b
- 背景: #f8fafc

### 組件
- 卡片：白底 + 陰影
- 按鈕：藍色主按鈕，灰色次按鈕
- 輸入框：灰色邊框

### API 需求（給工程師）
- GET /admin/dashboard - 儀表板數據
- GET /admin/players - 玩家列表
```

### 互動規格
```
## 玩家搜尋流程

1. 輸入玩家名稱 → 實時搜尋
2. 選擇玩家 → 進入詳情頁
3. 點擊封禁 → 確認對話框 → 執行

需要的 API:
- GET /admin/players/search?q=
- PATCH /admin/players/:id/ban
```

## 🚀 第一天快速開始

### Step 1: 建立設計系統
```bash
[設計] 遊戲的全局設計系統
- 色彩方案（主色、次色、背景）
- 排版規則（字體、大小、行高）
- 間距系統（margin, padding）
- 按鈕、表單、卡片基礎樣式
```

### Step 2: 設計後台
```bash
[設計] @admin 後台管理系統完整 UI
包括：儀表板、玩家管理、道具編輯
```

### Step 3: 工程師接手
```bash
工程師看 ADMIN_UI_SPECS.md
[實現] @admin 開發
```

**整個流程**: 1天完成設計系統 + 後台設計 ✨

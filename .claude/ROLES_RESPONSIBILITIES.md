### 全棧工程師 (你) - 核心系統開發

#### 開發區域
- ✅ **職業系統**: 技能、數值、平衡

- ✅ **玩家系統 API**: GET/POST/PATCH 玩家資訊

## 🔄 日常工作流示例

### 新增功能: 道具編輯器

#### 第 1 天 - 設計師
```
任務: [設計] @item 道具編輯器 UI
輸出:
- 設計稿 (Figma)
- 互動流程說明
- API 需求清單:
  * GET /admin/items/:id
  * PATCH /admin/items/:id
時間: 2-3 小時
```

#### 第 2-3 天 - 你 (全棧)
```
任務: [實現] @item 道具編輯 API
看到: ADMIN_UI_SPECS.md (設計規格)
做: 
- 實現 GET/PATCH API
- 資料庫驗證
- 單元測試
輸出: API 文檔 + 測試通過
時間: 4-6 小時
```

#### 第 4 天 - 設計師
```
任務: [改] @item 根據 API 反饋微調
調整: 欄位順序、驗證提示
更新: ADMIN_UI_SPECS.md
時間: 1 小時
```

#### 第 5 天 - APP 開發 (未來)
```
任務: [實現] @item 道具編輯頁面
看到: 最新設計 + API 文檔
實現: React/Vue 編輯頁面
時間: 6-8 小時
```

**總耗時**: 5 天 (vs 單人 7-10 天) ⏱️
